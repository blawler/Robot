Hermes Agent

This application is a personal assistant that accesses the signed-in user's own Google data (Gmail, Calendar, Drive, Contacts, Sheets, Docs) via OAuth 2.0. All processing happens on the account holder's own local machine. No data is stored on third-party servers.

Privacy Policy

  • Used only with the owner's own Google account.
  • No personal data is sold, shared, or used for advertising.
  • All data stays under the account holder's control in Google.
  • To revoke access or have data associated with this app removed, go to Google Account → Third-party access and remove this app.
